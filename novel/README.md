# Blood Debt / The Merge — novel canon

Source of truth for the fiction this game shares a universe with.
Duy, the Ratkin, the warden's keeping place, and the System's court all originate here.

- `chapters/` — manuscript, one file per chapter (cold open through Ch 16)
- `Atlantis_LitRPG_Story_Bible_v1.md` — canon: world rules, characters, System design
- `Series_Architecture_10_Books_v1.md` — ten-book arc
- `blood-debt-writing.skill` — writing skill (voice, craft laws, audit procedure)
- `BLOOD_DEBT_COMPLETE_HANDOFF.md` — everything in one file for onboarding an AI session

Key canon for Fwoosh: Duy dies in Ch 7 holding a portcullis against the warden, after the
party's accidental massacre of nineteen Ratkin non-combatants in Ch 4. His last words are
about taking his mother to Da Lat.
